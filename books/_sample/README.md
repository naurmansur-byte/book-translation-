# _sample — калибровочный фрагмент

Временный проект для проверки навыка `book-translation` перед началом
работы над полной книгой.

- `source/` — сюда положите файл с турецким фрагментом (1–2 страницы,
  txt/md/docx — любой текстовый формат подойдёт).
- `translation/` — сюда будет сохранён перевод.

После настоящей книги эта папка удаляется/переименовывается по образцу
для реального проекта (см. `CLAUDE.md` в корне репозитория).
