# Starter glossary: Turkish Islamic-topic terms → Russian

Default renderings for common terms in contemporary Turkish writing on
Islamic topics. This is a starting point, not a closed list — extend it
with every book-specific term you encounter, in the same format, in a
per-project glossary file (see `SKILL.md`, Step 2).

**Convention used throughout:** keep the term close to its established
Arabic-origin Russian Islamic-literature form (not a domesticated
paraphrase), and add a short translator's note on **first use only** when a
term is likely unfamiliar to a general Russian reader. After the first
noted occurrence, use the term plain — the note isn't repeated, and the
project glossary is what keeps the rendering itself consistent for the rest
of the book.

If a project or publisher already has its own house style (a specific
existing Quran/hadith translation it follows, a specific footnote format),
that house style overrides these defaults — record the override in the
project glossary rather than here.

## Handling terms not in this table

1. Check whether an established Russian rendering already exists in
   Russian-language Islamic publishing (transliterated from Arabic, not
   invented from the Turkish spelling) — prefer that.
2. If genuinely novel or highly book-specific, transliterate consistently
   and add a note on first use.
3. Record the decision in the project glossary immediately, with the page/
   location of first use, so it can be checked in the Step 5 self-check
   pass.

## What *not* to do

- Don't translate a specific ritual/doctrinal term into a generic Russian
  word that erases what's specific about it ("namaz" → "молитва",
  "haram" → "плохо/запрещено" as a loose paraphrase).
- Don't drop ﷺ / (r.a.) / rahimehullah-type formulas because they read as
  visual clutter in Russian — they're part of what the author wrote, every
  time they occur.
- Don't invent a new Russian rendering for a term that already has an
  established one in existing Russian Islamic literature.
- Don't over-gloss: once a term has had its first-use note, stop explaining
  it again — repeated inline explanation is itself a distortion of the
  author's plain, unglossed use of the term throughout the rest of the book.
